Projects

  1. #01 May 2026 live

    Collaborative Developer Workspace

    A real-time collaborative IDE — co-edit code, chat live and run it in a sandbox.

    • React + Monaco Editor front end with Django Channels over WebSockets; edits synced across server processes through a Redis channel layer.
    • Root-caused recurring WebSocket drops to a Redis client timeout and fixed it.
    • Python, C++ and JavaScript execute in isolated Docker containers — no network, CPU and memory capped.
    • Secure DRF APIs with Google OAuth 2.0 + JWT; 59 Jest and 76 pytest tests (≥95% coverage) on every push via GitHub Actions; Render Blueprint infra + Vercel front end.

  2. #02 Jan 2026

    Email Automation Agent (mailoo)

    Turns a plain-English request into personalised, tone-aware emails for each recipient.

    1. fetch contacts
    2. analyze intent
    3. clarify
    4. compose
    5. preview
    6. send
    • Three services — React front end, Django REST back end, LangGraph agent server — with Django proxying agent runs and forwarding the user's JWT so the agent only sees that user's contacts.
    • Matches recipients by relation, adapts tone per contact, and keeps a human in the loop to approve before sending.
    • JWT-secured DRF endpoints plus Gmail API integration over OAuth 2.0.
